# 📚 Asistencia PNF - Sistema de Control de Asistencia

Sistema web para el registro y gestión de asistencia de estudiantes universitarios, integrado con Supabase.

## 🚀 Características
- ✅ Login con autenticación segura
- ✅ Registro de asistencia en tiempo real
- ✅ Filtros por PNF, proceso, trayecto, ambiente
- ✅ Reportes en PDF
- ✅ Panel de administración
- ✅ Gestión de profesores y asignaciones

## 🛠️ Tecnologías
- **Frontend:** HTML5, Tailwind CSS (CDN), JavaScript (ES6)
- **Backend:** Supabase (Auth + Database + Edge Functions)
- **Librerías:** SweetAlert2, jsPDF, jsPDF-autoTable

## 📋 Requisitos
- Navegador moderno (Chrome, Firefox, Edge)
- Conexión a internet
- Cuenta en Supabase
